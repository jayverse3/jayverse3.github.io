# UniPat AI logo

- Files: `unipat.png` (black) and `unipat-white.png` (white), both 140 × 138 with transparent backgrounds.
- Official website: https://www.unipat.ai/
- Official standalone icon: https://cdn.unipat.ai/static/favicon/favicon-192.png
- Both files derive from the official 192 × 192 transparent PNG linked by the website, replacing the approximate, manually redrawn SVG variants.
- The crop keeps every nontransparent pixel: x=26, y=27, width=140, height=138. Only empty borders were removed; no tracing, resampling, or geometric changes were applied.
- The black and white versions set RGB to 0 or 255 respectively while preserving the source alpha value of every retained pixel, including antialiased edges. The colors are baked into the PNGs, with no runtime filter or brand-specific scaling.
