# Default social preview

`social-preview.png` is the 1200 × 630 homepage sharing image approved on 2026-10-05.
It combines the site's existing `hachiware.jpg` avatar with the owner's name,
research interests, domain, and site colors. The layout was exported from HTML/CSS;
the avatar was not redrawn or recolored. No reference website artwork is included.

This is a replaceable default, not an article-specific illustration. Set an
article's `image` front matter to use its own cover; otherwise the SEO template
falls back to `_config.yml`'s `og_image`. Replacing this PNG does not require an
image generation service or an additional build dependency.
