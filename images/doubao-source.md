# Doubao logo

- Source: [LobeHub Icons](https://github.com/lobehub/lobe-icons)
- Requested gallery page: https://lobehub.com/zh/icons/doubao
- Current gallery: https://icons.lobehub.com/
- Color variant: `doubao.svg`, downloaded from https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/doubao-color.svg
- White variant: `doubao-white.svg`, based on the LobeHub monochrome asset: https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/doubao.svg
- The color asset is unchanged. In the white variant, only the root fill was changed from `currentColor` to `#fff` for use as an external image; the vector paths and any original opacity values are unchanged. No CSS filter is required.
